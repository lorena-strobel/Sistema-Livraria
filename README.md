# 📚 Sistema de Gerenciamento de Livros

Um sistema de cadastro e gestão de livros desenvolvido em Java

## 📋 Funcionalidades

- ✅ Cadastro de livros
- ✅ Distinção entre livros físicos e digitais
- ✅ Entrada de dados via teclado
- ✅ Organização por categorias

## 🎯 Tecnologias

- Java
- Git/GitHub

## 📁 Classes Principais

- **Livro**: Classe base com atributos comuns
- **LivroFisico**: Especialização para livros físicos
- **LivroDigital**: Especialização para livros digitais
- **CadastroLivrosApp**: Classe principal do sistema
- **Teclado**: Utilitário para entrada de dados
